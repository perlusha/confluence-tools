# Простановка плановой даты согласования в строки согласующих

Скрипт: `Set-ApprovalDates.ps1`

Обходит дерево Confluence, находит листы ФТТ и проставляет в строки согласующих
плановую дату согласования из поля **07.01**.

---

## Запуск

```powershell
$env:CONFLUENCE_URL = 'https://confluence.example.com'
$env:CONFLUENCE_PERSONAL_TOKEN = '<PAT>'

# план по всему дереву (ничего не пишет)
.\Set-ApprovalDates.ps1 -Root 467853802

# одна страница — план и запись
.\Set-ApprovalDates.ps1 -Only 123456797
.\Set-ApprovalDates.ps1 -Only 123456797 -Apply
```

| параметр | смысл |
|---|---|
| `-Root` | корневая страница дерева |
| `-Only` | обработать только одну страницу (проверка) |
| `-Apply` | записать; без него — только план |
| `-MaxPages N` | ограничить число страниц |
| `-Insecure` | не проверять TLS-сертификат |

---

## Правила

Страница обрабатывается, только если **01. Наименование отчетного документа = «ФТТ»**.

Дата берётся из поля **07.01. Плановая дата согласования**. Если оно пусто — страница
не трогается.

В строках `NN. Согласующий N`:

- дата ставится, только если **согласующий заполнен** (в строке есть ссылка на человека).
  Если стоит один статус без человека — строка пропускается;
- дата ставится, если **живой статус** согласующего не «Согласован» и не «Отменен»;
- если дата в строке уже есть — она **перезаписывается** датой из 07.01;
- у строк со статусом «Согласован»/«Отменен» **ничего не меняется** (даже если дата стоит).

Дата вставляется сразу после пилюли статуса:

```html
</ac:structured-macro><br /><time datetime="2026-10-08" /> </ac:task-body>
```

Статус берётся **живой** — из реестра приложения
(`GET /rest/handy-macros/2.0/status-macro/{macroid}?contentId={pageId}`), а не из снимка
`Status` в теле страницы: снимок бывает устаревшим (в примере у согласующего с живым
статусом «Подготовка» в теле стоял «Согласован»).

---

## Проверено

- **Идемпотентность:** на странице-примере 505158626 (даты уже стоят) — **0 изменений**.
- **Тестовая запись:** 123456797 → v86. Три строки («Согласующий 1», «6», «7», статус
  «На согласовании») получили дату 2026-10-08; строки со статусом «Согласован» — нет.
  Разметка совпадает с эталоном.
- **Незаполненные согласующие:** 467855838 (статусы без людей) — страница пропущена.

---

## Объём

По дереву 467853802: 118 страниц с полем 01, из них **117 «ФТТ»**, у **114** заполнено 07.01.
Остальные пропускаются.
